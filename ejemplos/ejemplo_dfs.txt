# ================================================================
#   EJEMPLO PARA BUSQUEDA POR PROFUNDIDAD (DFS)
# ================================================================
#
#   DFS va lo mas profundo posible por la primera rama que encuentra.
#   Si no llega a la meta, retrocede (backtracking) y prueba otra.
#
#   Grafo:
#
#           A
#          / \
#         B   C
#        / \   \
#       D   E   F
#            \
#             G  <- META
#
#   DFS explorara primero la rama izquierda:
#     A -> B -> D  (llega al fondo, sin vecinos, retrocede)
#     A -> B -> E -> G  (encuentra la meta!)
#
#   Nota: el orden de exploracion depende del orden en que
#   esten las transiciones en el archivo.
# ================================================================
