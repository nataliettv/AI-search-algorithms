#
#   Grafo:
#
#           A
#          / \
#         B   C
#        / \   \
#       D   E   F
#            \
#             G  <- META (nivel 3 desde A)
#        
#   Iteracion 0: solo explora A.  X
#   Iteracion 1: explora A, B, C.   X
#   Iteracion 2: explora A, B, D, C, D, E, F   X
#   Iteracion 3: explora A, B, D, C, D, E, F -> META
#
#   se puede ver como "repite" trabajo en cada iteracion,
#   es normal en IDDFS
