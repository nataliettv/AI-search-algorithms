# DLS EJEMPLO
#
#   DLS es igual que DFS pero se detiene al llegar al limite.
#   Con este ejemplo puedes ver que pasa segun el limite que elijas:
#
#   Grafo:
#
#           A
#          / \
#         B   C
#        / \   \
#       D   E   F
#            \
#             G  <- META
#
#
#   La meta G esta a 4 pasos de A
#   Niveles:  A=0, B=1, C=1, D=2, E=2, F=2, G=3
#
#   Si pones limite = 2: no llega (G esta en nivel 3), sin solucion
#   Si pones limite = 3: llega exactamente a G, encuentra solucion
#   Si pones limite = 6: tambien llega, el limite simplemente no se alcanza
#
#   probar con limite 2, 3 y luego con limite 4 para ver la diferencia

ESTADOS
A G

TRANSICIONES
A B 1
A C 1
B D 1
B E 1
C F 1
E G 1
