# ================================================================
#   EJEMPLO PARA BUSQUEDA AVARA (GREEDY)
# ================================================================
#
#   La Busqueda Avara solo mira h(n): la estimacion de que tan
#   lejos esta cada nodo de la meta. Ignora el costo real.
#
#   Grafo:
#
#           A
#          / \
#         B   C
#        /     \
#       D       G  <- META
#        \
#         G  <- META (camino caro)
#
#   h(n) = estimacion de distancia a G:
#     h(A)=3, h(B)=2, h(C)=1, h(D)=1, h(G)=0
#
#   La avara elegira C porque tiene h(C)=1, el menor.
#   Llega por A -> C -> G con costo real = 10 + 1 = 11
#
#   Pero el camino optimo real era A -> B -> D -> G con costo = 1+1+1 = 3
#   La avara se equivoco porque solo miro h(n) y no el costo real.
#
#   Este ejemplo demuestra que la Busqueda Avara NO es optima.
# ================================================================

ESTADOS
A G

TRANSICIONES
A B 1
A C 10
B D 1
C G 1
D G 1

HEURISTICAS
A 3
B 2
C 1
D 1
G 0
